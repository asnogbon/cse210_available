# What is version control and why is it important?

Version control can be defined as a system that records, tracks, and monitors the changes on a project as people and teams works on it over time, allowing the project to be reviewed or reverted to specific previous versions whenever needed.
One of the benefit of version control is the ability to revert to a stable version if you make a mistake or break your code
Example of version control in software development team : When a team is workin on a project then made a mistake and added the wrong information .the version control command can be use to retrive the more stable version before the error was added.
An example of code used is: git commit
